# Курсовой проект: База данных вакансий с hh.ru

Проект для сбора и анализа вакансий с сайта HeadHunter с сохранением в базу данных PostgreSQL.

## 📌 Описание проекта

- Получение данных о компаниях и их вакансиях через API HeadHunter
- Автоматическое создание базы данных и таблиц (если их нет)
- Сохранение данных в PostgreSQL
- Анализ вакансий:
  - Список всех компаний и количество вакансий у каждой компании
  - Список всех вакансий с указанием компании, зарплаты и ссылки на них
  - Средняя зарплата по вакансиям
  - Список вакансий с зарплатой выше средней
  - Поиск вакансий по ключевому слову


## ⚙️ Зависимости

* python = "^3.13"
* requests = "^2.32.3"
* psycopg2 = "^2.9.10"


## 🔧 Установка

- Склонируйте репозиторий:
```commandline
https://github.com/GostischevAndrey/job_vacancies_database_hh
```
- Установите зависимости с помощью `poetry`:
```commandline
poetry install
```
- Активируйте виртуальное окружение:
```commandline
poetry shell
```
